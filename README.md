# 📌 GOM

GOM è un RPG (Role Playing Game) thriller con interfaccia grafica realizzato in JavaFX.

Il gioco è ispirato alla short story horror di Harlan Ellison:
[I Have No Mouth, and I Must Scream](https://en.wikipedia.org/wiki/I_Have_No_Mouth,_and_I_Must_Scream).

Nel corso di diverse giornate, il giocatore incontra vari NPC e deve decidere se fidarsi  
o meno delle informazioni che ciascuno di loro fornisce.

Le scelte compiute influenzano i punti esperienza ottenuti e determinano il livello finale raggiunto.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle 9.4.0

### Scaricare il progetto

```bash
git clone https://github.com/Elia320-neo/GOM.git
cd GOM
```

### Build del progetto

```bash
./gradlew build
```

### Esecuzione

```bash
./gradlew run
```

---
## 🎮 Comandi

- **Freccia sx:** per selezionare un oggetto a sinistra
- **Freccia dx** per selezionare un oggetto a destra 
- **Mouse pointer:** per selezionare un qualsiasi oggetto 
- **Invio:** per confermare l'oggetto selezionato

## 🤖 Uso di strumenti di AI
Durante la realizzazione del progetto sono stati utilizzati strumenti di AI per:

* modellare la conoscenza (def. concetti del dominio, responsabilità e gerarchie)
* generare template per classi e funzioni come prima versione NON stabile
* comprendere e gestire gli errori di compilazione

Ogni elemento prodotto dall'AI e integrato nel progetto, è stato: 

* compreso ed analizzato 
* modificato ed adattato manualamente al fine di realizzare una versione stabile
* testato e caricato sul repository remoto
